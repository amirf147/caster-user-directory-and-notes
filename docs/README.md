# Caster Documentation

Welcome to the Caster documentation directory. This folder contains all the architectural blueprints, technical deep dives, and feature explanations for this voice programming toolkit. 

To make it easy to find what you need, the documents are organized into specific categories rather than a flat, overwhelming list:

## Directory Structure

*   📁 **`architecture/`**
    *   Contains high-level design documents, Thread Architectures, and Architecture Decision Records (ADRs).
*   📁 **`features/`**
    *   Contains specific feature implementations, such as App Switcher logic, Window Switching documentation, and Foot Pedal configurations.
*   📁 **`framework_explainers/`**
    *   Contains educational breakdowns of underlying technologies like Dragonfly internals (e.g., DictList analysis, Rule deep dives).
*   📁 **`troubleshooting/`**
    *   Contains diagnostics, bug explanations, crash reports (e.g., Kaldi crashes, UIA thread errors), and debugging findings.
*   📁 **`legacy_notes/`**
    *   Contains older, deprecated reference notes from earlier development phases. These are kept for reference but may not reflect the current system state.
*   📁 **`prompts/`** & 📁 **`kaldi_engine/`** & 📁 **`wayfinder-uia-threading/`**
    *   Additional subdirectories containing specific resources and targeted ticket information.

If you are adding a new document, please place it into the most relevant folder above rather than the root directory.
